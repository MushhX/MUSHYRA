# VS Code language support

This folder contains a small local extension for `.mux` file association, TextMate syntax highlighting, block indentation, bracket matching and snippets. It does not provide a language server or semantic diagnostics.

Open this folder in VS Code and press **F5** to launch an Extension Development Host. Open any `.mux` file in that window to see the grammar and snippets. The extension does not add dependencies to Mux or change how scripts run; use `mux file.mux` in the terminal.
